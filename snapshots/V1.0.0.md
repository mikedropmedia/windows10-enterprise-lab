# Version 1.0.0 – Initial Lab Environment Setup

**Date**: April 2025  
**Author**: mdMedia

### Key Milestones:
- Created a Windows 10 Education VM in VirtualBox
- Skipped Unattended Install to avoid product key errors
- Mounted ISO and manually installed Windows
- Activated using Microsoft Azure Dev Tools for Teaching key
- Installed Guest Additions manually from CD
- Created a snapshot after full installation and activation

### Lessons Learned:
- VirtualBox's Unattended Install isn't ideal for controlled labs
- Guest Additions may require manual CD access and execution
- It's crucial to snapshot after every major milestone
