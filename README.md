# Windows 10 Enterprise Lab

This repo documents the full setup and evolution of my personal lab environment using Windows 10 Education (Enterprise equivalent) inside VirtualBox.

This is where I:
- Build and snapshot a licensed, secure base Windows system
- Practice system administration and hardening
- Simulate network security events using Kali
- Document real-world learning from setup to troubleshooting

Lab structure:
- `lab-setup/` contains install & setup walkthroughs
- `snapshots/` tracks version milestones
- `TASKS.md` tracks current and future labs

This lab is designed to grow. I’ll update it with new security challenges, MMC workflows, group policy scenarios, and logs from hands-on tests.
